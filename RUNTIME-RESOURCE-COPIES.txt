Resource fixed-copy optimization; resource subsystem remains UNFINISHED
=======================================================================

The default runtime now proves eligible16/144-byte fixed copies safe through
a continuously live mutable local anchor, then copies with exact SSE2 chunks.
See crates/dearust-path/SAFETY-MEMORY.txt for the ownership/page proof, exact
guest PCs and retained negative-path checks. No guest address becomes a Rust
reference. The optimization does not cache mappings, masks or process identity.
There are45 private paths.o globals; process-ids.o retains its13 C globals and
is byte-identical to the preceding resource ABI batch on both supported targets.
The public/import sets and unchanged original i386 full-link slice are preserved.

This is not completion of the resource subsystem. Its production resource ABI
still uses the previous Linux-backed conversion and EOVERFLOW containment.
The separate resource_policy/resource_view modules and owned server/loader
builders are integration work, not the policy used in these measurements.
Full unsigned-limit ownership, XNU physical enforcement and generic CPU costs
remain independently open. No new source-port or retired-target count is claimed.

Validation
------------
202 ordinary Rust tests,11 compile-fail checks,35 Python checks, strict fmt and
Clippy, all explicit pinned differential/Darwin ABI gates pass. Native/Darwin
staging repeats byte-identically. Both full links preserve public/import sets
and original i386 bytes. Native guarded copies pass plain and C ASan/UBSan with
the signal-runtime sanitizer settings documented in SAFETY-MEMORY.txt. Native
fixture/assembly are independently reviewed; Rust/assembly are not instrumented.

Actual guests pass resource ABI/fault/pressure/waited-child checks, three signal/
fork/RPC probes,30 retained regressions, filesystem checks,29 application cases
(28 strict plus one previously established timestamp normalization),16 utilities
and three selected GUI applications. TextEditor input is visually checked; the
hidden GUI helper/display are cleaned up. Original C defect observations remain
failures in comparative reports; wrapper exit1 is not relabeled a global pass.
Installed kernel/server/loader, reference sources/builds and prior paired server
hashes remain unchanged. Owned prefixes are separate from existing user prefixes.
