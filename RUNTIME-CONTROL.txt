Subsystem extensions and ABI
-----------------------------
No new crates: dearust-process adds setpgid/setsid to its identifiers feature;
dearust-fd adds umask/getdtablesize. Package count stays 20. The process-ids.o
artifact has seven exports, fd.o nine, and query-only process.o remains matching-
only. All original C symbols and original guest syscall wrappers remain.
Grouped input replacement inserts each Rust object once and removes the new
four original emulation sources along with their previous grouped sources.

setpgid raw Linux 109 receives signed PID/PGID; setsid raw 112 takes no arguments.
Original int result narrowing, one errno conversion, namespace mutation policy,
zero unused raw slots and direct EINTR propagation are retained. No caches,
retry, locks, new process-global Rust state or cancellation hook are introduced.
Tests confine group/session changes to owned fork children and verify the parent.

umask raw 95 preserves unsigned 32-bit zero-extension, original int result
narrowing and once-only Linux-to-Darwin conversion. getdtablesize calls retained
C sys_getrlimit(BSD_RLIMIT_NOFILE=8), preserving its NOFILE-minus-one compatibility
policy; Linux limits are not substituted directly. The helper status narrows
from long to C int. A negative status is already Darwin errno and returns
unchanged. Every nonnegative status clamps unsigned rlim_cur to INT_MAX.

The complete original xnu_rlimit ABI is 176 bytes: two u64 fields followed by 20
reserved LP64 longs, eight-byte alignment. Rust initializes the full structure,
asserts size/alignment/field offsets and passes bounded live stack storage to C.
The callback must not retain the pointer or unwind. Native fixtures write all 176
bytes, including the reserved tail, to verify storage compatibility. No heap,
caller pointers, path storage or limit cache is added. Original GPL attribution,
source/header hashes and retained-helper provenance are recorded.

CPU and memory evidence
-----------------------
New raw wrappers retain a single eight-byte syscall argument/alignment push.
getdtablesize has 184 bytes of native local stack subtraction in both original C
and Rust; this includes its full 176-byte ABI object and alignment. Return-address
and callee storage are excluded. It adds no per-process retained buffer. The
native full fd/process-ID objects remain at 126 bytes of shared read-only errno
data each. Their file sizes 4224/3712 bytes include older grouped operations and
metadata, so they are not directly comparable with the new-C-only frame groups.
The complete matching dylib file shrinks 1312 bytes: 872352 -> 871040. None of these
figures establishes process-RSS changes.

common errno conversion. Original sources/includes and raw records are retained.
