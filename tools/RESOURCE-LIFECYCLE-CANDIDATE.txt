Owned resource lifecycle continuation (unfinished)
===================================================

resource-lifecycle-current-index.json indexes this continuation separately from
the immutable resource-prepared-registration-verification.json. Every native
derivative retains its own binary/input hashes; results are not a combined fault
matrix for the final candidate. These C/C++ prerequisites neither activate
unsigned resource ownership nor add Rust replacements or target retirements.

Implementation
----------------
The Registry reserves EIDs before factories and map nodes before foreign handles.
Selected task/thread C source now follows the selected bridge object's adjacent
source, preserving Rust lockset dying/destruction callbacks. Owned builds freeze
inputs, rebuild all12 server translation units, compile checked C changes and
record all selected objects/archives and C compilation commands.

Private task/thread preparation checks VM, IPC, importance, psynch and turnstile
stages and retains partial ownership explicitly. Kernel-lane abort releases only
acquired state; thread dying decrements active_thread_count once. Every opaque C
context independently owns its generation, so retained old handles keep C++
owners alive and late disposal cannot clear replacements. Resume validates its
expected generation under the Thread lock through reserved queue insertion.
StackPool reserves its cache and honors capacity without the old off-by-one.

Process death marks ResourceState synchronously and stops timer rearming. Owned
channels are destroyed outside the Process lock; exit fanout and foreign cleanup
use reserved events/jobs. ResourceState's embedded job precedes its real gate
semaphore. Startup-owned cleanup TLS removes the previous64MiB allocator arena
reservation; the lane still adds a default-stack pthread, an open performance gate.

Process/Mach notification packets retain fixed storage across EAGAIN. Weak C
callback promotion defers final C detach. Port-set unlink atomically publishes
shutdown, posts the read semaphore and interrupts an existing wait, closing a
reproduced lost wakeup when callback return preceded its next semaphore wait.

Exec prepares a replacement task, thread and five semaphores before publishing.
It pins predecessor handles, releases both owner locks for C preparation, then
relocks and revalidates exact live ownership before commit. An embedded cleanup
capsule retires handles after unlocking. Physical exec has already occurred;
failure is terminal bookkeeping, not image rollback. Checkin Call/reply storage
is reserved before Registry publication. Message tokens preserve signal/S2C
deferrals; intrusive nodes merge into ordinary FIFO/batched transport without
queue allocation. Terminal exec errors queue their reserved reply before death.
