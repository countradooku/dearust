Subsystem and behavior
-----------------------
One no_std dearust-path crate replaces eight per-operation crates: symlinkat,
readlinkat, unlinkat, linkat, renameat, mkdirat, faccessat and fchmodat. It also
ports rmdir and truncate. Package count 20 -> 13. The eleven original C exports
include do_linux_fchmodat. Logical per-operation ABI modules remain, with one
safe in-place path copier and shared errno data. All eight moved ABI modules
are byte-identical to their predecessor implementations at commit 9c1efeb.
Existing fixes/flag policies remain, including faccessat's ignored raw flags,
fchmodat's historical symlink no-op and inherited metadata/check/use race.

paths.o replaces ten unique original emulation inputs and is inserted once.
--paths-object replaces the eight earlier pathname object switches; combining
those switches is rejected. Historical individual options remain usable with
historical artifacts. The original thread-cwd bridge is required alongside the
existing lstat integration. lstat/fstatat and other subsystem crates stay separate.
No new production stubs, allocator, cache, locks or process-global state are added.

rmdir preserves thread-local cwd, expansion flags 0 and raw Linux unlinkat 263
with the expanded descriptor/path and AT_REMOVEDIR 0x200. Result narrows to int,
negative errors convert once and every nonnegative result returns zero. The
final symlink is not followed. Its existing NULL EFAULT handling is retained.
truncate preserves thread-local cwd, FOLLOW 1 expansion, raw truncate 76 with
expanded absolute path and full signed 64-bit length, int result narrowing and
one errno conversion. It does not incorrectly pass a dirfd to raw truncate.

Both copy directly into initialized final 4096-byte ABI buffers. NULL truncate
now returns EFAULT instead of crashing; unterminated/overlong paths return
ENAMETOOLONG rather than unbounded strcpy overflow. The new guest probes exit
132 (rmdir long path) and 139 (truncate NULL) on the previous runtime and pass
with Rust. Non-NULL invalid pointers retain the wider caller-validity contract.
No returned-array intermediate or path cache is introduced; two-path operations
still need exactly two live buffers. See SAFETY.txt for all preserved boundaries.
