Locked Linux host-tool dependencies
==================================

The x86_64 Linux darling-coredump executable links rustix 1.1.5,
bitflags 2.13.2 and linux-raw-sys 0.12.1. Cargo.lock records registry checksums.
These dependencies do not enter the no_std Darling runtime objects.

The MIT alternative is selected for these dependencies. The original copyright
statements and MIT notices follow; retain this file when redistributing the
host executable. Other target-only Cargo.lock packages are not linked by the
measured linux_raw build. This file supplements the project's GPL-3.0-or-later
notices, which continue to apply to the converter itself.
