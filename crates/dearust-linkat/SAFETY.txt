linkat: bounded x86_64 descriptor-relative runtime migration
================================================================

Source: xnu darling/src/libsystem_kernel/emulation/src/xnu_syscall/bsd/impl/unistd/linkat.c
at fa29287aa2f0115271e091f1031f53c9e024005d, GPL-3.0-or-later. Pinned and
matching local C sources are byte-identical. Darling/upstream attribution and
licenses continue to apply; bounded copier derives from dearust-readlinkat.

Two initialized repr(C) Expanded values hold exactly the two final 4096-byte
paths, uint32 flags and int32 fd. Copying writes directly into them; no allocator,
intermediate path array, cache, mutex or panic runtime is introduced. Safe copier
reads no more than 4096 bytes and stops at NUL. NULL input returns Darwin -EFAULT;
unterminated input returns -ENAMETOOLONG instead of unbounded strcpy overflow.
Non-NULL inputs must be readable through NUL or 4096 bytes. Arbitrary invalid
non-NULL pointers are outside the existing in-process caller contract.

Unsafe is limited to abi.rs pointer reads, C exports and foreign ABI calls.
Original C atfd preserves BSD_AT_FDCWD/per-thread cwd, and original vchroot
expands source before destination. Both paths are copied before any expansion.
Helpers must not unwind and must preserve path termination. Raw seven-argument
Linux syscall 265 receives expanded descriptors and paths. The return value
narrows to int exactly as C, then maps Linux errno to negative Darwin errno.
Source follows its final symlink only for BSD flag 0x40; destination never
follows. C atflags_bsd_to_linux executes only after both expansions; its invalid
sentinel 1 returns -EINVAL. Other flag policy stays at the existing C boundary.
Success returns the narrowed syscall result, matching original linkat.

Scope is partial and x86_64 only. Native fixtures use explicit path/TLS adapters
with actual Linux syscalls; guest fixtures separately exercise real Darling paths.
