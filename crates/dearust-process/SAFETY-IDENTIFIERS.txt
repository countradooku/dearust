Feature queries retains the existing process-query modules. Feature identifiers
adds only these seven exports and the optional existing dearust-errno dependency;
default enables both. Identifier-only staging does not include procfs query code.

Unsafe is confined to raw C calls and export attributes in identifiers.rs. Only
linux_syscall is imported, and must preserve the declared seven-argument ABI and
not unwind. Linux39/110/111 are getpid/getppid/getpgrp; Linux121/124 receive signed
32-bit pid sign-extended for getpgid/getsid. Linux109 receives signed pid/pgid
for setpgid; Linux112 setsid takes no arguments. These calls retain kernel
process-group/session mutation policy. Unused slots are zero. Each raw
result narrows to C int before negative Linux-to-Darwin errno conversion once.
getppid maps zero to one AFTER conversion, retaining launchd's PID-namespace
root behavior. EINTR is returned directly without retry. No caller pointer,
heap, TLS/atfd lookup, cache, process-global state, mutex or panic runtime is used.

Scope is x86_64 only. Native fixture records exact syscall ABI, synthetic narrow
returns, errno and one-call EINTR, plus real process/session identity. Guest
fixture independently exercises fork-child parent/group/session identity and an
isolated child setsid/setpgid; parent process identity remains unchanged.
Tests confine mutation to owned fork children.
